# RJ Offroad · 资料与下载中心

客户资料仓库，提供操作手册、配件说明、维修资料和下载入口。

- [打开下载中心](https://erfinderwx.github.io/rj-offroad-library/)
- [查看文件目录](site/files/)
- [视频及大型资料包](https://github.com/erfinderwx/rj-offroad-library/releases)
- [资料目录架构](docs/DIRECTORY.md)
- [如何补充和更新资料](docs/维护说明.md)

本仓库为公开下载库，访客无需 GitHub 账号即可下载已发布文件。文件权利属于原权利人；公开下载不额外授予开源许可。

## 文件组织

| 目录 | 内容 |
| --- | --- |
| `01-manuals` | 操作说明与用户手册 |
| `02-certifications` | 认证、检测及适用性文件 |
| `03-maintenance` | 改装、维修与保养 |
| `04-accessories` | 配件使用及安装 |
| `05-specifications` | 产品规格及配置差异 |
| `06-developer-resources` | 接口、SDK、示例、固件 |
| `07-cad-models` | CAD、图纸与三维模型 |
| `08-testing` | 测试、验收及质量资料 |
| `09-after-sales` | 售后条款、服务说明和 FAQ |
| `10-media-training` | 培训、图片与视频 |

同一份文件只有一个主位置，再通过产品、类别和版本信息检索。未收到文件的分类已预留目录；下载中心只列实际文件和已登记的资料入口。

PDF 等小文件保存在 `site/files/`；大型视频和模型包保存在 Releases。下载中心在每次合并至 `main` 后自动更新。客户页面支持中文、英文、德文；下载的原始文件保持原语言与原内容。
